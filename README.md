# 📝 Notion Clone with Reflex

A modern, Notion-inspired note-taking application built with Python and Reflex framework. Features dynamic page management, block-based editing, and a clean, responsive design.

## ✨ Features

- **Dynamic Pages**: Create and navigate between multiple pages seamlessly
- **Block-Based Editing**: Add text, headings, and todo blocks to any page
- **Real-time Editing**: Live updates without page refreshes
- **Optimized State Management**: No ripple effects - efficient updates using immutable data structures
- **Notion-Like Design**: Clean UI with Tailwind CSS styling
- **Responsive Layout**: Works on desktop and mobile devices

## 🚀 Tech Stack

- **Backend**: Python with Reflex framework
- **Frontend**: React (auto-generated by Reflex)
- **Styling**: Tailwind CSS
- **State Management**: Reflex state with optimized updates
- **UI Components**: Radix UI (via Reflex)

## 🛠️ Installation

### Prerequisites
- Python 3.8+
- Node.js 16+ (automatically installed by Reflex)
- Git

### Setup Steps

1. **Clone the repository**
   ```bash
   git clone <your-repo-url>
   cd notion_app
   ```

2. **Install Python dependencies**
   ```bash
   pip install -r requirements.txt
   ```

3. **Initialize Reflex (this will install Node.js and frontend dependencies)**
   ```bash
   reflex init
   ```

## ▶️ Running the Application

### Development Mode
```bash
reflex run
```

The app will be available at:
- Frontend: http://localhost:3000
- Backend: http://localhost:8000

### Production Build
```bash
reflex export
reflex run --env prod
```

## 🎯 Key Features Explained

### Optimized State Management (No Ripple Effects)

The application uses advanced state management techniques to prevent unnecessary re-renders:

- **Immutable Updates**: Uses `model_copy()` for state changes
- **Computed Properties**: `@rx.var` decorators for derived state
- **Efficient List Operations**: Targeted updates instead of full list replacements
- **Clean Separation**: Page data and UI state are properly isolated

### Dynamic Page System

- **Page Navigation**: Click page names in sidebar to switch instantly
- **New Page Creation**: "New Page" button creates and switches to fresh pages
- **Persistent State**: All pages and their content are maintained in memory
- **Unique IDs**: Each page has a UUID for reliable identification

### Block-Based Editing

- **Text Blocks**: Simple text content
- **Heading Blocks**: Larger, bold text for titles
- **Todo Blocks**: Checkable items with strikethrough when completed
- **Real-time Updates**: Changes save instantly without manual saving

## 🔧 Development

### Adding New Block Types

1. Update the `Block` model in `state.py`
2. Add rendering logic in `notion_app.py`
3. Update the add block buttons

### Customizing Styling

- Modify Tailwind classes in component `class_name` attributes
- Update the theme configuration in `rxconfig.py`
- Add custom CSS in the `.web/styles/` directory
